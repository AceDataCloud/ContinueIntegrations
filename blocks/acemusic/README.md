# ACE Music for Continue

Copy [block.yaml](block.yaml) to `.continue/mcpServers/acemusic-acedatacloud.yaml` in the intended workspace. Supply `ACEDATACLOUD_API_TOKEN` using Continue's secret configuration and reload Continue. This is an independent local block; Continue Hub publication is separate.

From [Applications](https://platform.acedata.cloud/console/applications?utm_source=continue&utm_medium=referral&utm_campaign=evergreen&utm_content=acemusic_continue_api_key), choose **General application** or **Initialize General Application**, then create a service key with ACE Music access. Use `acemusic_list_models` to inspect supported models. Check [pricing](https://platform.acedata.cloud/services/acemusic?utm_source=continue&utm_medium=referral&utm_campaign=evergreen&utm_content=acemusic_continue_pricing) before using `acemusic_generate_music`, generating lyrics, uploading, covering or blending references. Save `task_id`, then call `acemusic_get_task` with the original ID. Return completed candidates from a partial group. [简体中文](README_zh-CN.md)
